# Decision register

Executives asking "where are we?" get one row per open decision. The register is not a maturity score.

Status is only `PASS`, `BLOCKED`, or `INSUFFICIENT EVIDENCE`. Leave status blank until a gate result exists for that row. A gate result evaluates the supplied record for that decision. It is not an audit of the underlying system, measurement, people, or evidence.

The same project may have several rows. Keep exploring can be `PASS` while operate is `BLOCKED`, because the intended use and subject/scope differ. Do not average the rows. Do not report a count such as "3 of 6."

| Decision | Intended use | Subject / scope | Required claim | Status | Owner | Next evidence | Stop date |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

**Required claim** is the weakest claim sufficient for that decision: Access, Output, Deliverable, Operating capability, Outcome, or Value.

**Owner** is the person accountable for the next evidence and the stop date. The owner is not a score.

**Stop date** is when the decision is restricted or stopped if the next evidence is still missing.
