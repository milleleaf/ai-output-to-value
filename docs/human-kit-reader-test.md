# Human-kit reader test

This file used to make one reader session a release check. That check is withdrawn.

A session with one person is one observation. It has no sampling frame, so it cannot represent founders, directors, managers, operators, or clients. The release support for which claim a published result can carry is the [public case corpus](public-case-corpus.md).

The eight questions remain the way to read a decision or a corpus row. They are printed on the meeting brief. They are not an examination that one reader passes for anyone else.

Do not record a session in this file as release evidence.
